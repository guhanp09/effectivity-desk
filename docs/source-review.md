# Source study: AD 2026-09-01

Source: [Federal Register, April 29, 2026](https://www.govinfo.gov/content/pkg/FR-2026-04-29/pdf/2026-08306.pdf),
effective June 3, 2026. The captured public PDF and hash are retained. This note
summarizes selected provisions; it is not the full controlled compliance record.

The stated unsafe condition links water-system leakage to migration into critical
flight equipment. This connects a mechanical coupling and installation/retention
problem with aircraft electrical/electronic system exposure. It does not establish
that every leak causes an electrical failure. Installation location, configuration,
inspection findings and the applicable controlled maintenance data matter.

| Provision | Review implication |
| --- | --- |
| (c), (d) | 787-8/-9/-10, as specified in the referenced 2022 RB; ATA 38 Water/waste. Model alone is insufficient |
| (g), (h) | Retained actions use the 2022 Issue 001 RB with an explicit June 29, 2023 reference-date exception |
| (i) | Prior-action credit has specified documents, scope and timing; not generic credit for any earlier repair |
| (j), (k) | New actions depend on the 2025 Issue 002 RB; the specified Issue 001 date reference is replaced by this AD's effective date |
| (l) | New-action completion terminates the retained action only for the identified airplanes; neither a document update nor model name proves completion |
| (m) | The old coupling installation prohibition depends on replacement history at the same inspection location; current part number alone is insufficient |
| (n) | FAA/authorized ODA AMOC authority is specified; this repository supplies none |

The public discussion describes new inspections for 787-8/-9 while retaining
787-10 in the wider rule. The engine therefore does not use the new-inspection
model discussion to declare all 787-10 review obligations absent. Missing actual
RB membership remains UNKNOWN for both overall and new-action effectivity.

The two old coupling PNs and the location-history condition in the paragraph (m)
exercise come from the public AD. The illustrated part histories are invented.
A matching prohibition condition is an escalation cue, not permission to replace
or install a part. No invented history supplies manufacturer effectivity evidence.

The actual incorporated RB tables, accomplishment instructions, detailed time
limits, configuration records and any later AD/AMOC status are unavailable here.
Those gaps block a real due-date calculation or compliance conclusion. The separate
SB-SIM-PUMP-01 corpus exists to exercise the mechanics without filling those gaps
with fabricated manufacturer data.

[FAA AD overview](https://www.faa.gov/regulations_policies/airworthiness_directives)
explains the legal role of ADs. A manufacturer bulletin and an enforceable AD are
not treated as interchangeable. This study is limited to the captured FAA source;
it makes no finding about another authority's requirements.
